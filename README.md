## Overview

Lossy simulates the audio artifacts of lossy streaming compression — MP3, AAC, and codec-like degradation — with a Bitrate knob that continuously degrades audio from pristine to heavily compressed.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Lossy** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Codec Simulation** | Models MP3 and AAC psychoacoustic masking artifact characteristics |
| **Bitrate Knob** | Single knob continuously degrades audio from perfect to heavy compression |
| **Artifact Types** | Pre-echo, ringing, muddiness, and stereo smearing artifact controls |
| **Lo-Fi Design** | Use as a creative lo-fi effect for drums, vocals, and sound design |
